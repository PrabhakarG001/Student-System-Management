# Student Management System

A simple desktop application built with Python and Tkinter for managing student records.

## Features
- **Add Students**: Save new student records with ID, Name, and Marks.
- **Search Students**: Find a student's information using their unique ID.
- **Delete Students**: Remove a student record from the system.
- **List All Students**: View a list of all current students.

## Project Structure
- `main.py`: The entry point for the application. Run this file to start the system.
- `gui.py`: Contains the Tkinter-based user interface.
- `logic.py`: Implements the backend logic for manipulating student data.
- `database.py`: Handles file-based or database data operations.
- `styles.py`: Defines the UI styling (colors, fonts, etc.).
- `students.txt`: Stores the student data.

## How to Run
Ensure you have Python installed on your system.
1. Open your terminal or command prompt.
2. Navigate to the project directory.
3. Run the following command:
```bash
python main.py
```
